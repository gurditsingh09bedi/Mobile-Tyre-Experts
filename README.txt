Steps:
1. GitHub pe naya repo banao, jaise tag_mobiletyre
2. index.html aur contact.vcf upload karo, dono same folder mein
3. Settings > Pages > Deploy from a branch > main / root > Save
4. Link: https://<github-user>.github.io/tag_mobiletyre/
5. Yeh link NFC chip pe likho (NFC Tools app > Write > URL)
